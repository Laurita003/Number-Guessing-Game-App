# Number Guessing Game App

Ein kleines Zahlenspiel, bei dem man eine geheime Zahl mithilfe von Hinweisen erraten muss.

Live Demo: https://laurita003.github.io/Number-Guessing-Game-App/

## So funktioniert's

* Klicke auf „Neues Spiel“ oder „Spielen“.
* Gib deine Zahl ein.
* Folge den Hinweisen (zu niedrig / zu hoch), um dich anzunähern.
* Mit jedem Versuch kommst du der richtigen Zahl näher.
* Versuche, die Zahl mit möglichst wenigen Versuchen zu erraten!

## Features

* Zufällige Generierung der geheimen Zahl
* Direkte Rückmeldung nach jedem Versuch
* Anzeige der Versuche und des Spielfortschritts
* Schnelles Neustarten einer Runde
* Responsives Design

## Verwendete Technologien

* HTML5
* CSS3
* JavaScript

## Lokal starten

1. Repository herunterladen oder klonen.
2. Den Projektordner in Visual Studio Code öffnen.
3. `index.html` im Browser öffnen.
Alternativ kann das Spiel über GitHub Pages gespielt werden.
